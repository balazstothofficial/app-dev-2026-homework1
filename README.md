# App Development 2026 — Homework 1

This project contains the Kotlin lecture exercises, their reference solutions,
and **Homework 1: Tiny Text Utility**.

## Getting started

1. Clone your personal assignment repository created by Classmoji.
2. Open the repository root as a Gradle project in IntelliJ IDEA.
3. Use JDK 21 and let Gradle finish importing the project.
4. Open `src/main/kotlin/homework/Homework1.kt` and run its `main` function.

The complete homework tasks and requirements are in `Homework1.kt`.
Implement your solution there; add functions or files in the `homework` package
as needed.

## Reference material

- `src/main/kotlin/lecture/`: lecture exercises.
- `src/main/kotlin/lecture/solution/`: solutions to those exercises.

Homework solutions are not included.

## Build

With JDK 21 installed, run:

```sh
./gradlew build
```

On Windows, use `gradlew.bat build`. This checks that the project builds; it
does not grade your homework. Run the homework interactively from the IDE to
try its behavior.

## Submission

Commit and push your work to your personal assignment repository. Follow the
deadline and submission instructions shown in Classmoji.
