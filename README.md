# App Development 2026 — Homework 1

This project contains the Kotlin lecture exercises, their reference solutions,
and **Homework 1: Tiny Text Utility**.

## Getting started

1. Clone your personal assignment repository created by Classmoji.
2. Open the repository in Android Studio.
3. Open `src/main/kotlin/homework/Homework1.kt`.

The complete homework tasks and requirements are in `Homework1.kt`.
Implement your solution in the file or create new files in the `homework` package
as needed.

## Reference material

- `src/main/kotlin/lecture/`: lecture exercises.
- `src/main/kotlin/lecture/solution/`: solutions to those exercises.

## Submission

Commit and push your work to your personal assignment repository. 
See the deadline in Classmoji.
